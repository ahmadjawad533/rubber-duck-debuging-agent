# Screenshots & Visual Assets

This folder contains screenshots of Rubber Duck in action for hackathon documentation and articles:

1. `idle_screen.png`: The initial greeting ("Quack. What's broken?") with the 3 clickable example bugs and clean typography.
2. `socratic_dialogue.png`: Rubber Duck asking focused single questions, with syntax-highlighted code and copy buttons.
3. `celebration_confetti.png`: Solved celebration animation with confetti, recap lesson card, and learner rating buttons.
4. `results_dashboard.png`: Live hackathon stats modal showing aggregate metrics from DynamoDB and CloudWatch.
5. `cloudwatch_metrics.png`: CloudWatch console showing the custom EMF metrics in the `RubberDuck` namespace.
